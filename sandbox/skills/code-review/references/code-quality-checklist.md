# 代码质量清单

## 错误处理

### 要标记的反模式

- **吞异常**：空 `except`，或者只打条日志就算了
  ```python
  try:
      ...
  except Exception:
      pass                      # 静默失败
  try:
      ...
  except Exception as e:
      logger.info(e)            # 记了就忘
  ```
- **过宽的捕获**：捕 `Exception`/`BaseException` 基类，而不是具体类型
- **错误信息泄露**：把堆栈或内部细节暴露给用户
- **漏掉错误处理**：可失败的操作（IO、网络、解析）外面没有处理
- **异步错误**：任务异常无人 await、`create_task` 后不取结果、缺错误边界

### 要核对的实践

- [ ] 异常在合适的边界被捕获
- [ ] 错误信息对用户友好（不暴露内部细节）
- [ ] 日志带足上下文，够定位问题
- [ ] 异步异常被正确传播或处理
- [ ] 可恢复的错误有明确的兜底行为
- [ ] 严重错误会触发告警/监控

### 该问的问题

- 「这个操作失败时会怎样？」
- 「调用方能知道出问题了吗？」
- 「凭现有日志能定位这个错误吗？」

## 性能与缓存

### 计算密集

- **热路径上的昂贵操作**：循环里编译正则、解析 JSON、做加解密
- **阻塞主线程**：同步 IO、重计算没有放线程池/异步
- **重复计算**：同一个结果算了多次
- **缺记忆化**：纯函数被反复用相同入参调用

### 数据库与 IO

- **N+1 查询**：循环里逐条查询，而不是批量
  ```python
  # 不好：N+1
  for user_id in user_ids:
      user = await db.query("SELECT * FROM users WHERE id = %s", user_id)

  # 好：批量
  users = await db.query("SELECT * FROM users WHERE id = ANY(%s)", user_ids)
  ```
- **缺索引**：在没索引的列上查询
- **过度取数**：只要几列却 `SELECT *`
- **没有分页**：一次性把整个数据集读进内存

### 缓存问题

- **该缓存没缓存**：重复的外部调用、DB 查询、重计算
- **缓存没有 TTL**：脏数据会一直供给下去
- **缓存没有失效策略**：数据更新了缓存没清
- **缓存键碰撞**：键的唯一性不够
- **把用户相关的数据缓存在全局**：安全与隐私问题

### 内存

- **无界集合**：会无限增长的 list/dict
- **大对象滞留**：一直持有引用，GC 回收不掉
- **循环里做字符串拼接**：用 `"".join(parts)` 而不是 `s += part`
- **整个文件读进内存**：该逐行/流式读的却 `read()`

### 该问的问题

- 「这个操作的时间复杂度是多少？」
- 「数据量放大 10 倍/100 倍会怎样？」
- 「这个结果可以缓存吗？应该缓存吗？」
- 「能不能批量做，而不是一条一条来？」

## 边界条件

### 空值处理

- **漏判空**：在可能为 None 的对象上取属性
- **真值判断的坑**：用 `if value` 时，`0` 和 `""` 是合法值也会被判为假
- **滥用可选链**：`a?.b?.c?.d` 层层兜底，掩盖了结构本身的问题
- **None 与缺省值混用**：没有统一约定

### 空集合

- **空列表没处理**：代码默认列表里一定有元素
- **空字典的边界**：对空 dict 做遍历或取 keys
- **取首尾元素**：`arr[0]` 或 `arr[-1]` 没有先判长度

### 数值边界

- **除零**：除法前没有检查
- **整数溢出**：大数超出安全范围
- **浮点比较**：用 `==` 而不是按精度比较
- **负值**：本不该为负的下标或计数
- **差一错误**：循环边界、切片、分页

### 字符串边界

- **空字符串**：没有当作边界处理
- **只有空白字符**：通过真值判断，实际上等于空
- **超长字符串**：没有长度限制，造成内存或展示问题
- **Unicode 边界**：Emoji、RTL 文本、组合字符

### 典型的危险写法

```python
# 危险：没判空
name = user.profile.name

# 危险：不判长度就取下标
first = items[0]

# 危险：除法不检查分母
avg = total / count

# 危险：真值判断会漏掉合法值
if value:      # 0、""、[] 都会被当成假
    ...
```

### 该问的问题

- 「如果是 None/空会怎样？」
- 「如果这个集合是空的会怎样？」
- 「这个数的合法范围是多少？」
- 「边界上（0、-1、最大值）会发生什么？」
